# 資料抓取策略與備援邏輯（Data Sourcing & Fallback）

給 claude.ai（Web 模式）用。爬蟲常抓不到動態圖表或被擋，本檔規範來源優先序、抓不到時的備援算法、以及 Consensus 比對規則，降低「查不到就編」的風險。

---

## 一、資料來源優先序（Source Fallback Priority）

各項數據依「公信力 + 可爬取性」排序，由上而下嘗試：

### 官方/公信力來源（第一優先）
- **公開資訊觀測站 MOPS**（mops.twse.com.tw）：財報、月營收、重大訊息、股利分派——最權威，財報數據以此為準
- **證交所 TWSE / 櫃買中心 TPEx**：每日收盤、三大法人、融資券、成交量
- **集保結算所**：股權分散、大戶持股

### 財經資訊站（第二優先，圖表/整理較友善）
- **Goodinfo!**：本益比河流、PB、殖利率、月營收整理（表格化，較好抓）
- **財報狗 statementdog**：財務比率趨勢、體質評分
- **Yahoo 奇摩股市**：即時報價、基本資料、新聞
- **玉山證券 e.Fund / 富果 Fugle / 神秘金字塔**：籌碼、大戶

### 券商/媒體（第三優先，用於 Consensus 與新聞）
- 各大券商報告摘要、鉅亨網、經濟日報、工商時報、天下/遠見/商周（法人預估、目標價、法說會展望）

### 規則
- 財務數字（EPS、營收、股利）**以 MOPS/證交所為最終依據**，媒體數字有出入時以官方為準
- 每個關鍵數據在報告中標註來源與日期
- web_fetch 優先抓表格型頁面（Goodinfo、財報狗），動態 JS 圖表常抓不到，改抓其文字/表格區

## 二、備援算法（Fallback Strategy）

抓不到理想數據時，用以下替代，並在報告中明確註明「使用備援算法」。

### 本益比河流圖抓不到
→ 退回用「近 5 年最高 PE 與最低 PE 的算術平均」當合理 PE 中樞，現價 PE 與之比較判斷貴賤。或用「近 5 年 PE 區間 + 目前落點」文字描述，取代圖形。

### PB-Band（循環股）抓不到
→ 同上邏輯，用近 5-10 年最高/最低 PB 平均當中樞。

### 法人 Consensus（券商預估）抓不到
→ 退回用「歷史 EPS 成長率外推 + 最新月營收 YoY」做粗估，並**明確標示這是自行推估、非市場共識**，下修該結論的 confidence。

### 完整財報抓不到（僅有片段）
→ 只用已查得的項目分析，缺項標「無法取得」，不用其他數字回推編造。缺關鍵項時整體 confidence 下修。

### 集保大戶資料抓不到
→ 模組 4 的大戶/散戶部分標「本次無法取得集保分散資料」，僅以三大法人與融資券判斷。

### 通則
- **寧可標「無法取得」，不可推估後當成事實陳述**
- 任何備援算法產出的數字，都要在該處註明「（備援估算）」

## 三、市場 Consensus 比對（Positive / Negative Surprise）

機構定價看的是「實際 vs 預期」，不只是歷史數字。

### 要抓什麼
- 搜尋「{公司} EPS 預估」「{公司} 目標價」「{公司} 券商 評等」
- 取外資 + 本土券商的**預估 EPS 均值**與**目標價均值**（能取幾家算幾家，標明樣本數）

### 怎麼比
1. **估值面**：現價 vs 券商目標價均值 → 算折溢價（現價低於目標價均值 X%＝上檔空間），填入訊號卡 `vs Consensus`
2. **財報面（財報公布後）**：實際 EPS vs 財報前市場預估 EPS
   - 實際 > 預期 → **Positive Surprise**（優於預期，偏多催化）
   - 實際 < 預期 → **Negative Surprise**（不如預期，偏空）
   - 符合 → In-line
3. **展望面**：法說 guidance vs 市場原本預期（見 catalysts-macro.md）

### 注意
- Consensus 會隨時間變動，標註取得日期
- 樣本太少（如僅 1 家）時降低權重，註明
- 「利多出盡」現象：即使 Positive Surprise，若股價已提前反映，仍可能跌，需搭配籌碼與催化劑綜合判斷

## 四、查證流程檢查點

開始寫報告前自檢：
- [ ] 股價/市值 —— 有無標日期？
- [ ] 最新月營收 —— YoY/MoM/累計？
- [ ] 估值（PE/PB/殖利率）—— 官方或 Goodinfo？抓不到有無用備援並註明？
- [ ] 三大法人 + 融資券 —— 近 5/20 日？
- [ ] Consensus —— 有無查券商目標價均值？
- [ ] 產業 profile —— STEP 0.5 是否已判定並套用？
- [ ] 缺失項 —— 是否都標「無法取得」而非編造？
