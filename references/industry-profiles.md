# 產業別評估套組（Industry-Specific Profiles）

STEP 0.5 判定產業後，用本檔的對應套組覆寫八大模組的指標。每個套組列出：停用指標、替換指標、估值錨點、評分調整。

---

## 金融股（金控 / 銀行 / 壽險 / 產險）

代表：2880 華南金、2881 富邦金、2882 國泰金、2884 玉山金、2885 元大金、2886 兆豐金、2891 中信金、2892 第一金、2801 彰銀等。

### 停用指標
- 毛利率、營業利益率（金融業無「銷貨成本」概念，毛利率失去意義）
- 流動比率、存貨相關（銀行資產結構不同）
- 月營收 YoY 的解讀權重下調（金融業月營收波動大且季節性強，改看稅後淨利與每股淨值）

### 替換 / 新增核心指標
- **NIM（淨利差 Net Interest Margin）**：銀行放款收益率減資金成本，反映本業獲利能力。趨勢向上為佳
- **逾放比（NPL Ratio）**：逾期放款占總放款比。越低越好，一般 < 1% 屬健康；突升是重大警訊
- **備抵呆帳覆蓋率（Coverage Ratio）**：越高代表抗風險能力越強
- **資本適足率（BIS / 普通股權益比 CET1）**：法定門檻以上，越高越穩健但過高代表資金運用效率低
- **壽險業額外看**：EV（內含價值 Embedded Value）、避險後經常性收益率、匯兌與避險成本、淨值比（壽險受利率與股債市波動影響淨值劇烈）
- **股東權益報酬率 ROE、股價淨值比 PB**：金融股估值主錨

### 估值錨點
- **以 PB 為主、PE 為輔**。金融股長期 PB 區間相對穩定，看目前 PB 位於近 5-10 年區間位置
- 殖利率同樣重要（金融股為存股熱門標的）

### F-Score 評分調整（金融版）
替換原第 3、6、8 項：
- 原「盈餘品質(營業現金流>稅後淨利)」→ 改「逾放比 < 1% 且較去年未惡化」
- 原「流動性」→ 改「資本適足率高於法定要求且未下降」
- 原「毛利率」→ 改「NIM 較去年同期持平或上升」

## 景氣循環股（航運 / 面板 / 記憶體 DRAM / 鋼鐵 / 塑化）

代表：2603 長榮、2609 陽明、2610 華航、3481 群創、2409 友達、2408 南亞科、2002 中鋼、1301 台塑、1303 南亞、6505 台塑化等。

### 停用 / 淡化指標
- **單季 EPS 的絕對值與 PE**（最危險的陷阱）：景氣頂點時 EPS 爆發、PE 看起來極低，實則是賣點；景氣谷底 EPS 轉虧、PE 為負或極高，反而常是買點。**低 PE ≠ 便宜**
- 不以當期 PE 河流作為主要估值依據

### 替換 / 新增核心指標
- **PB-Band（歷史股價淨值比區間）**：循環股估值主軸。看目前 PB 位於近 5-10 年區間的哪個百分位。接近歷史 PB 下緣＝景氣谷底佈局區；接近上緣＝景氣過熱警戒
- **產能利用率（Capacity Utilization）與供需缺口**：查產業供需——擴產週期（供給增→殺價）或去化週期（供給收→報價漲）。航運看運價指數（SCFI、BDI）、面板/記憶體看報價（如 DRAM 現貨價、面板報價）、鋼鐵看盤價
- **在景氣循環的位置判斷**：擴張初期 / 過熱 / 衰退 / 谷底復甦，這決定整份報告的多空基調
- 自由現金流與負債結構（循環低谷能否撐過）

### 估值錨點
- PB-Band 為主，搭配「隔景氣循環的正常化 EPS」（normalized earnings，取一個完整循環的平均獲利）估算合理 PE，而非用當期異常 EPS

### F-Score 調整
- 第 4「ROE 趨勢」、第 9「營收動能」的解讀要放在循環脈絡下：谷底復甦期營收剛轉正比高基期衰退更有意義

## 營建股（建設 / 營造 / 開發）

代表：2542 興富發、2547 日勝生、5522 遠雄、2545 皇翔、9945 潤泰新、1808 潤隆等。

### 停用 / 淡化指標
- **單期營收與 EPS 的連續性**：營建業採「完工入帳」，交屋時營收與獲利集中認列，平時可能掛零。用月營收 YoY 判斷會嚴重失真

### 替換 / 新增核心指標
- **合約負債（Contract Liabilities）**：已預售收訂但未交屋的金額，是未來營收的先行指標。合約負債成長＝未來 1-3 年入帳能見度高
- **待售房地 + 在建工程存貨**：手上可賣的貨與正在蓋的貨
- **完工交屋排程（Pipeline）**：未來 2-3 年各建案的完工與交屋時間表，推估各年度可認列營收。這是營建股估值核心
- **推案量與去化率**：新推個案的銷售速度
- 土地儲備（land bank）與取得成本

### 估值錨點
- 看未來 2-3 年交屋 Pipeline 推估的每股獲利，而非 TTM（過去 12 個月）EPS
- PB 與每股淨值（含土地重估增值潛力）

## 高成長 / 生技研發股

代表：多數興櫃生技、新藥研發公司、尚未穩定獲利的高成長股（如部分 AI/軟體/雲端）。

### 停用 / 淡化指標
- **PE 與 F-Score 前段獲利項**：多數尚未獲利或獲利極不穩定，PE 為負或極高皆無參考性
- 傳統毛利率趨勢（研發期成本結構特殊）

### 替換 / 新增核心指標
- **PSR（股價銷售比 Price-to-Sales）**：無獲利成長股的主要估值法。與同業、與自身歷史 PSR 區間比較
- **R&D 占營收比重**：反映研發強度與未來動能
- **營收成長率（而非獲利）**：CAGR、QoQ 加速或減速
- **現金消耗率（Cash Burn Rate）與現金水位**：算出「跑道長度」（runway，現金還能燒幾季），是否需再增資（稀釋風險）
- **生技專屬里程碑（Milestones）**：三期臨床進度、FDA/TFDA 認證、藥證取得、授權金（授權合約 upfront + milestone payment）、專利到期。這些是股價催化劑核心

### 估值錨點
- PSR 為主；生技可用風險調整後 NPV（rNPV，把各期臨床成功機率折現）概念定性評估
- 明確標示「本益比不適用」，避免誤導

## ETF 專章（高股息 / 市值型）

代表：0050、006208（市值型）；0056、00878、00919、00929、00940（高股息）等。

**ETF 不走個股框架**，改用以下維度：

### 市值型 ETF（0050、006208 等）
- 追蹤指數與成分（前十大持股集中度，如 0050 台積電權重）
- **內扣費用（總費用率）**：長期複利下的關鍵，越低越好
- 折溢價（市價 vs 淨值 NAV）
- 追蹤誤差

### 高股息 ETF（0056、00878、00940 等）
- **配息穩定度與頻率**（月配 / 季配 / 半年配）：看近年配息連續性，而非單次高殖利率
- **成分股選股邏輯**：依「歷史殖利率」「預估殖利率」還是「品質因子」選股，決定填息能力與波動
- **內扣費用**
- **成分股調整審核期**（重要：見 chip-flow.md）：換股期間會產生大量被動資金買賣，影響成分股股價
- 規模（AUM）與流動性、折溢價
- **避免殖利率陷阱**：高配息若來自本金（配息率 > 實際收益）不可持續
