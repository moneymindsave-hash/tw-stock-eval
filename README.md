# tw-stock-eval

台股個股綜合評估 Claude Skill —— 針對台灣上市櫃股票的機構級分析框架，從基本面、估值、籌碼面、股利政策等八大模組，輸出標準化的投資訊號。

由 [MoneyMind 錢腦](https://www.threads.com/@moneysave72?hl=zh-tw) 開發並開源分享。

## 這是什麼

一個給 Claude 使用的 Skill。當你要求分析台股個股時（例如「分析 2330」「評估台積電」「0056 適合存股嗎」），Claude 會依照這份框架，產出結構化的個股分析報告。

核心設計原則：**所有數據必須來自即時查證，禁止使用訓練記憶中的股價或財務數字。**

## 八大分析模組

1. 投資論點摘要
2. 基本面體檢（月營收動能、EPS、毛利率、ROE 杜邦拆解、現金流品質）
3. 估值評估（本益比河流、股價淨值比、現金殖利率、同業比較）
4. 籌碼面分析（三大法人買賣超、融資融券、外資持股）
5. 股利政策（配息紀錄、填息紀錄、預估殖利率）
6. 品質評分（台版 9 分 F-Score）
7. 三大關鍵風險
8. 目標價與觀察區間（Bull / Base / Bear 三情境）

最終輸出標準化的 INVESTMENT SIGNAL 訊號卡，並列出論點失效條件。

## 使用環境

支援兩種模式，自動判斷：
- **claude.ai**：透過 web search + web_fetch 取得公開資料
- **Claude Code**：透過 FinMind API 直連證交所資料

## 安裝方式

下載 `SKILL.md`，放入你的 Claude skills 目錄即可。

## 使用範例

- 「分析 2330」→ 完整八模組報告
- 「2317 籌碼面怎麼樣」→ 只跑籌碼面模組
- 「比較 2330 和 2454」→ 兩檔並列比較
