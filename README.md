# tw-stock-eval

台股個股綜合評估 Claude Skill —— 針對台灣上市櫃股票的機構級分析框架，依產業屬性動態切換指標，從基本面、估值、籌碼面、股利政策、催化劑到總經連動共十大模組，輸出標準化的投資訊號。

由 [MoneyMind 錢腦](https://www.threads.com/@moneysave72?hl=zh-tw) 開發並開源分享。

## 這是什麼

一個給 Claude 使用的 Skill。當你要求分析台股個股時（例如「分析 2330」「評估玉山金」「0056 適合存股嗎」），Claude 會依照這份框架，先判斷個股所屬產業、套用對應的指標套組，再產出結構化的個股分析報告。

核心設計原則：**所有數據必須來自即時查證，禁止使用訓練記憶中的股價或財務數字。**

## 動態產業分類

分析前先識別個股類型，套用對應的指標覆寫，避免一套框架打天下造成失真：

- **金融股**：改看 NIM、逾放比、資本適足率、壽險 EV
- **景氣循環股**：改用 PB-Band、產能利用率、供需缺口，避免「低 PE 買在景氣頂點」
- **營建股**：改看合約負債、待售房地、完工交屋 Pipeline
- **高成長／生技股**：改用 PSR、R&D 占比、臨床／認證里程碑
- **ETF**：走專章（配息穩定度、內扣費用、成分審核期）
- **一般製造／科技／內需**：套用標準模組

## 十大分析模組

1. 投資論點摘要
2. 基本面體檢（月營收動能、EPS、毛利率、ROE 杜邦拆解、現金流品質）
3. 估值評估（本益比河流、股價淨值比、現金殖利率、同業與市場 Consensus 比較）
4. 籌碼面分析（三大法人、融資融券、千張大戶集保、高股息 ETF 效應）
5. 股利政策（配息紀錄、填息紀錄、預估殖利率）
6. 品質評分（台版 9 分 F-Score，金融股另有專屬版本）
7. 三大關鍵風險
8. 前瞻性與催化劑（法說會指引追蹤、股價催化劑時間軸）
9. 大盤與總經連動（指數影響力、匯率敏感度、Fed／央行週期加減分）
10. 目標價與觀察區間（Bull / Base / Bear 三情境）

最終輸出標準化的 INVESTMENT SIGNAL 訊號卡，並列出論點失效條件。

## 使用環境

支援兩種模式，自動判斷：
- **claude.ai**：透過 web search + web_fetch 取得公開資料，含來源優先序與備援算法
- **Claude Code**：透過 FinMind API 直連證交所資料

## 檔案結構

​```
tw-stock-eval/
├── SKILL.md                        主檔（流程調度與十大模組）
└── references/
    ├── industry-profiles.md        各產業替換指標與評分調整
    ├── catalysts-macro.md          催化劑、法說會指引、匯率敏感度、總經週期
    ├── chip-flow.md                大戶散戶集保判讀、高股息 ETF 成分審核時程
    └── data-sourcing.md            Web 模式來源優先序、fallback 備援、Consensus 比對
​```

Claude 依分析需要載入對應的 reference 檔，不需每次全讀。

## 安裝方式

- **claude.ai**：Settings → Skills，上傳整個資料夾（含 references）
- **Claude Code**：將整個 `tw-stock-eval` 資料夾放入 skills 目錄

## 使用範例

- 「分析 2330」→ 判為科技股，完整十模組報告
- 「分析 2884」→ 判為金融股，套用金融指標套組
- 「長榮 2603 現在能追嗎」→ 判為景氣循環股，PB-Band + 供需缺口為主
- 「0056 適合存股嗎」→ 走 ETF 專章
- 「比較 2330 和 2454」→ 兩檔並列比較
