# tw-stock-eval

台股個股綜合評估 Claude Skill —— 從基本面、估值、籌碼面、股利政策四個面向，輸出標準化的投資訊號。

## 這是什麼

一個給 Claude 使用的 Skill。當你要求分析台股個股時（例如「分析 2330」「評估台積電」「2317 現在能買嗎」），Claude 會依照這份 SKILL.md 的框架，產出結構化的個股分析。

## 分析面向

- **基本面**：月營收動能、獲利能力
- **估值**：本益比、股價淨值比等相對估值
- **籌碼面**：三大法人買賣超、融資融券變化
- **股利政策**：填息紀錄、殖利率
- 台灣在地化調整的 9 分 F-Score

## 使用環境

支援兩種模式：
- **claude.ai**：透過 web search 取得公開資料
- **Claude Code**：透過 FinMind API 取得資料

## 安裝方式

下載 `SKILL.md`，放入你的 Claude skills 目錄即可。
